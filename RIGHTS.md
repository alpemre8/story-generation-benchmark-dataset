# Rights and Redistribution Notice

## Scope of this public release

This repository intentionally does **not** redistribute full screenplay text. It contains identifiers, hashes, provenance metadata, derived scalar feature measurements, benchmark/task metadata, and research instrumentation.

## Third-party screenplay material

Rights in the underlying screenplays remain with their respective authors, studios, publishers, or other rightsholders. Historical public availability of screenplay files in an upstream Git repository is documented here as provenance; it is **not** treated as permission to relicense or redistribute the screenplay text.

The reconstruction helper in this repository operates only on screenplay files that a user already possesses locally. It does not download source text.

## STAGE_v0 and upstream source records

The release records immutable historical STAGE_v0 commit IDs, STAGE movie IDs, paths, Git blob hashes, and the original source URLs associated with the selected films. Those references are provided for scientific lineage and verification.
