# Changelog

## 1.0.1 — 2026-08-25

- Dataset-only public release.
- Removed non-dataset validation artifacts from the public package.

## 1.0.0 — 2026-08-25

- Initial public screenplay-text-free dataset release.
- Added 938 per-scene five-axis feature rows.
- Added portable TasksetV5 with 240 tasks and 48 base intervals.
- Added historical STAGE provenance and deterministic preprocessing specification.
- Removed raw screenplay text, local filesystem paths, localhost endpoints, caches, and request telemetry.
